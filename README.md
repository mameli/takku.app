# takku.app

The landing page of [Takku](https://github.com/mameli/takku), served by Cloudflare Workers at [takku.app](https://takku.app): every push to `main` is deployed with `npx wrangler deploy`, with no build step.

A single static page, without JavaScript, in `public/`: `index.html` and `style.css`. `wrangler.jsonc` tells Cloudflare to serve that folder as it is. It looks like a sheet of squared paper with a hand-drawn schematic of how Takku works; in dark mode it becomes a blueprint.

To preview it locally:

```sh
python3 -m http.server 8765 -d public
```

and open <http://localhost:8765>.

- The lines (frame, ruler, margin, boxes, circles, underlines) are drawn by hand as SVG strokes inside `style.css`, generated by `tools/strokes.py` (`python3 tools/strokes.py`); the diagram in the hero is generated by `tools/drawing.py` (`python3 tools/drawing.py public/index.html`). Only the squares of the paper are printed.
- `og.png` is the preview shown when the link is shared, drawn from the page by `python3 tools/og.py` (needs Google Chrome): run it again after changing the drawing or the title.
- `icon.png` (208px, twice the size of the icon in the title), `apple-touch-icon.png` (180px) and `favicon.png` are copies of the app icon from the Takku repository, scaled down.
- The fonts are self-hosted, so the page makes no requests to other sites: [Kalam](https://fonts.google.com/specimen/Kalam) and [Literata](https://fonts.google.com/specimen/Literata), both under the SIL Open Font License (`public/fonts/OFL-*.txt`).
