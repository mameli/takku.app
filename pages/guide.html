Using Takku

Recording takes one shortcut. The rest of this page is how to get better summaries: templates, a vocabulary and the names of the people you meet.

A meeting

  1. Start from the menu bar or with ⌃⌥⌘R, from any app. While Takku records, its icon is a red dot and the menu shows how long the meeting has lasted. with Suggest recording on, in Settings, General, a notification offers to start when a call begins
  2. The meeting note opens in Obsidian. Write your own notes under Personal notes: Takku never changes them, and uses them to steer the summary.
  3. Press ⌃⌥⌘M when something matters. That passage gets a ⭐ in the transcript, and the summary gives it priority.
  4. Press ⌃⌥⌘S to keep what’s on screen, a slide or a diagram. It marks the moment too, and the picture goes under the point of the summary that covers it and under its passage in the transcript. the model never sees the picture: Takku places it by the times the summary cites
  5. Stop from the menu or with ⌃⌥⌘R again. Takku finishes the transcript, writes the summary at the top of the note with the time of each point, links the transcript and gives the note a short title. A notification tells you when it’s done.

If Takku hears nothing from the microphone or from the call for 2 minutes, the menu says so. If it has heard nothing since the start, a notification tells you which permission to check.

Another summary

The template and the summary profile are chosen in the Takku menu. To write a meeting’s summary again, with another template or after an error, open Recent meetings and press Retry: Takku uses the template and profile selected now.

Choose Transcript as the profile to get only the transcript, with no summary.

Templates

A template is a Markdown file in ~/.takku/templates/: its text tells the model what to write and how, in your own words. Create one from Settings, Templates, then open it with Edit With, in any text editor.

The summary is written in the language of the meeting. To always get it in one language, add summary_language: en (or it, fr…) to the template’s frontmatter.

Vocabulary

Names, acronyms and technical words that speech recognition gets wrong go in ~/.takku/vocabulary.md, which you open from Settings, Vocabulary, Edit Vocabulary With. One term per line: the right spelling, then after = what is heard instead, then after | a short description. The last two are optional.

- Kubernetes = cubernetes, kubernetis
- dbt = di bi ti | data transformation tool
- Holacracy

The variants are replaced in the transcript as whole words, so don’t list one that is also an ordinary word. Every term goes to the model, which spells it right in the summary.

Speaker names

The transcript tells voices apart as Speaker 1, Speaker 2 and so on, and the summary names them when the call makes it clear who they are. When it can’t, read the transcript, write the names in the note’s frontmatter and press Retry:

speakers:
  - Speaker 1 = Mario Rossi
  - Speaker 3 = Anna Bianchi

Calendar

Turn on Use the calendar in Settings, General, and allow access. When a meeting starts during an event, the note takes the event’s name and lists who was invited, which helps the summary name the speakers. If the list is wrong, correct it in the note: it counts on the next Retry.

Hook

A hook takes each meeting somewhere else once Takku is done with it: Notion, Confluence, a git commit of your vault, anything a script can do. Put an executable at ~/.takku/hooks/after-processing: when a meeting is ready, and again after every Retry, Takku runs it with the paths of the meeting note and of the transcript.
