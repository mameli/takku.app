Takku

Using Takku

Recording takes one shortcut. The rest of this page is how to get better summaries: templates, a vocabulary and the names of the people you meet.

A meeting

  1. Start from the menu bar or with ⌃⌥⌘R, from any app. While Takku records, its icon is a red dot and the menu shows how long the meeting has lasted. when a call app holds the microphone for 15 seconds, a notification offers to start
  2. The meeting note opens in Obsidian. Write your own notes under Personal notes: Takku never changes them, and uses them to steer the summary.
  3. Press ⌃⌥⌘M when something matters. That passage gets a ⭐ in the transcript, and the summary gives it priority.
  4. Stop from the menu or with ⌃⌥⌘R again. Takku finishes the transcript, writes the summary at the top of the note with the time of each point, links the transcript and gives the note a short title. A notification tells you when it’s done.

If Takku hears nothing from the microphone or from the call for 2 minutes, the menu says so. If it has heard nothing since the start, a notification tells you which permission to check.

Another summary

The template and the summary profile are chosen in the Takku menu. To write a meeting’s summary again, with another template or after an error, open Recent meetings and press Retry: Takku uses the template and profile selected now.

Choose Transcript as the profile to get only the transcript, with no summary.

Templates

A template is a Markdown file in ~/.takku/templates/: its text tells the model what to write and how, in your own words. Create one from Settings, Templates, then open it with Edit With, in any text editor.

The summary is written in the language of the meeting. To always get it in one language, add summary_language: en (or it, fr…) to the template’s frontmatter.

Vocabulary

Names, acronyms and technical words that speech recognition gets wrong go in ~/.takku/vocabulary.md, which you open from Settings, Vocabulary, Edit Vocabulary With. One term per line: the right spelling, then after = what is heard instead, then after | a short description. The last two are optional.

- Kubernetes = cubernetes, kubernetis
- dbt = di bi ti | data transformation tool
- Holacracy

The variants are replaced in the transcript as whole words, so don’t list one that is also an ordinary word. Every term goes to the model, which spells it right in the summary.

Speaker names

The transcript tells voices apart as Speaker 1, Speaker 2 and so on, and the summary names them when the call makes it clear who they are. When it can’t, read the transcript, write the names in the note’s frontmatter and press Retry:

speakers:
  - Speaker 1 = Mario Rossi
  - Speaker 3 = Anna Bianchi

Calendar

Turn on Use the calendar in Settings, General, and allow access. When a meeting starts during an event, the note takes the event’s name and lists who was invited, which helps the summary name the speakers. If the list is wrong, correct it in the note: it counts on the next Retry.

Hook

A hook takes each meeting somewhere else once Takku is done with it: Notion, Confluence, a git commit of your vault, anything a script can do. Takku has no integrations of its own. It runs your script and hands it the files.

Put an executable at ~/.takku/hooks/after-processing. When a meeting is ready, and again after every Retry that succeeds, Takku runs it in your vault folder with two arguments: the path of the meeting note and the path of the transcript. The simplest hook commits the vault to git:

#!/bin/sh
# $1: the meeting note, $2: the transcript
git add -A && git commit -qm "Meeting: $(basename "$1" .md)"
  • Make it executable with chmod +x ~/.takku/hooks/after-processing. Without the file nothing happens: there is no setting to turn on.
  • A Retry runs it again, so update what the first run created rather than creating it twice. The note’s takku_id never changes: use it for that.
  • Every run is written to ~/.takku/hooks/after-processing.log, with the command to run it again by hand. If the script fails, a notification says so, and the meeting is not touched.
  • Homebrew’s tools are found, and a script still running after 5 minutes is stopped.
  • The script runs with Takku’s permissions, microphone included, and sends your meetings wherever you tell it to. Put there only code you trust.

Every meeting in Notion

A ready-made hook, notion.py, copies each meeting note (the summary and your notes) to a Notion page under a page you choose, and updates the same page after a Retry. It needs Python 3, from Homebrew or the Xcode Command Line Tools.

  1. In Notion’s developer portal, open Internal connections and create a new connection for your workspace, with read, update and insert content turned on. Copy its API token. a connection sees only the pages you share with it
  2. Save the token in the Keychain, pasting it when asked: 
    security add-generic-password -a "$USER" -s takku-notion -w
  3. Open the page the meetings will go under. In its ••• menu, choose Connections, Add connection, and pick yours. Copy the page’s link: its ID is the 32 characters at the end.
  4. Install the script, then write the page ID in PARENT_PAGE_ID at its top: 
    mkdir -p ~/.takku/hooks
curl -fsSL https://raw.githubusercontent.com/mameli/Takku/main/examples/hooks/notion.py \
  -o ~/.takku/hooks/after-processing
chmod +x ~/.takku/hooks/after-processing
open -t ~/.takku/hooks/after-processing
  5. Try it on a meeting you already have, then look for the page in Notion: 
    ~/.takku/hooks/after-processing "/path/to/vault/Meetings/a meeting.md"

From then on every meeting goes to Notion as soon as it is ready.
