Takku

Set up Takku

Install the app, allow the recording, then choose your vault and who writes the summary. You do it once.

You need a Mac with Apple Silicon and macOS 15 or later, and an Obsidian vault. Any folder works: Obsidian is only needed to open the notes.

Install

  1. Download Takku, open the zip and move Takku to Applications. With Homebrew: brew install --cask mameli/takku/takku
  2. Open Takku. macOS says it can’t verify the app, because Takku is signed but not notarized by Apple: press Done.
  3. In System Settings, Privacy & Security, scroll down, press Open Anyway next to Takku and confirm with your password.

To skip steps 2 and 3, run xattr -dr com.apple.quarantine /Applications/Takku.app in Terminal before opening Takku. On a Mac managed by your company, IT may block apps that aren’t notarized: you can build Takku from source instead.

Takku lives in the menu bar, not in the Dock.

First setup

  1. Start a meeting from the menu bar. macOS asks for the microphone and for System Audio Recording Only: allow both. The first time, Takku also downloads the transcription model, about 650 MB, and the menu shows the progress.
  2. Open Settings from the Takku menu and choose your vault under Obsidian Vault. Takku creates a Meetings folder, with a Notes template you can change.
  3. In Summary Profiles, add a profile: name, base URL, model, max context and, if the provider needs one, an API key, which is kept in the macOS Keychain. Press Test connection.
  4. If you want Takku to start with your Mac, turn on Open at login in Settings, General.

Profiles to start from

On your Mac
Start llama-server -hf ggml-org/gemma-4-E4B-it-GGUF:Q4_0 -c 32768, then use the base URL http://localhost:8080/v1 and the model ggml-org/gemma-4-E4B-it-GGUF:Q4_0, with no key. Ollama and LM Studio work too.
Regolo.ai, Italy
Base URL https://api.regolo.ai/v1, model gemma4-31b, with an API key.
Mistral, France
Base URL https://api.mistral.ai/v1, model mistral-medium-latest, with an API key.

Set max context to the model’s real limit: for a local server, the -c it was started with. To keep only the transcript, choose Transcript as the profile.

Takku doesn’t check where a provider processes your data: read its terms, and your company’s policy, before using it for real meetings.

Updating

With Homebrew, run brew upgrade --cask takku. Otherwise quit Takku, replace it in Applications with the new version and repeat steps 2 and 3 of the install. Your settings, profiles, API keys and models are kept.
