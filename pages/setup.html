Takku

Set up Takku

Install the app, allow the recording, then choose your vault and who writes the summary. You do it once.

You need a Mac with Apple Silicon and macOS 15 or later, and an Obsidian vault. Any folder works: Obsidian is only needed to open the notes.

Install

  1. Download Takku, open the zip and move Takku to Applications. With Homebrew: brew install --cask mameli/takku/takku
  2. Open Takku. It’s notarized by Apple, so it opens like any other app.

Takku lives in the menu bar, not in the Dock.

First setup

  1. The first time you open Takku, a welcome window walks you through the steps below. You can do each one later too.
  2. Choose your Obsidian vault. Takku creates a Meetings folder, with a Notes template you can change.
  3. Allow the microphone and System Audio Recording Only when macOS asks.
  4. Download the transcription model, about 650 MB. It’s prepared for your Mac once, which takes a few minutes. If you skip it, it happens during your first meeting.
  5. For summaries, open Settings from the Takku menu and, in Summary Profiles, add a profile: name, base URL, model, max context and, if the provider needs one, an API key, which is kept in the macOS Keychain. Press Test connection.
  6. If you want Takku to start with your Mac, turn on Open at login in Settings, General.

Profiles to start from

On your Mac
Start llama-server -hf ggml-org/gemma-4-E4B-it-GGUF:Q4_0 -c 32768, then use the base URL http://localhost:8080/v1 and the model ggml-org/gemma-4-E4B-it-GGUF:Q4_0, with no key. Ollama and LM Studio work too.
Regolo.ai, Italy
Base URL https://api.regolo.ai/v1, model gemma4-31b, with an API key.
Mistral, France
Base URL https://api.mistral.ai/v1, model mistral-medium-latest, with an API key.

Set max context to the model’s real limit: for a local server, the -c it was started with. To keep only the transcript, choose Transcript as the profile.

Takku doesn’t check where a provider processes your data: read its terms, and your company’s policy, before using it for real meetings.

Updating

With Homebrew, run brew upgrade --cask takku. Otherwise quit Takku and replace it in Applications with the new version. Your settings, profiles, API keys and models are kept.

Coming from a 0.x version: from 1.0 Takku is signed with an Apple Developer ID, so macOS asks once more for the microphone, the system audio and the calendars, and for your password to let Takku read your saved API keys (choose Always Allow).
