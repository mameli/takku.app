Takku

Set up Takku

Install the app, allow the recording, then choose your vault and who writes the summary. You do it once.

You need a Mac with Apple Silicon and macOS 15 or later, and an Obsidian vault. Any folder works: Obsidian is only needed to open the notes.

Install

  1. Download Takku, open it and drag Takku into Applications. With Homebrew: brew install --cask mameli/takku/takku
  2. Open Takku. It’s notarized by Apple, so it opens like any other app.

Takku lives in the menu bar, not in the Dock.

First setup

  1. The first time you open Takku, a welcome window walks you through the steps below. You can do each one later too.
  2. Choose your Obsidian vault. Takku writes each meeting in its Meetings folder.
  3. Allow the microphone and System Audio Recording Only when macOS asks.
  4. For screenshots during meetings (⌃⌥⌘S), allow Screen Recording too. It’s optional and works from the next launch: if macOS offers Quit & Reopen, Later is fine.
  5. Download the transcription model, about 650 MB. It’s prepared for your Mac once, which takes a few minutes. If you skip it, it happens during your first meeting.
  6. For summaries, the simplest is Takku Credit: paste the key from its email into the Takku Credit profile. Or open Settings from the Takku menu and, in Summary Profiles, add a profile: name, base URL, model, max context and, if the provider needs one, an API key, which is kept in the macOS Keychain. Reasoning and extra parameters are optional: see below. Press Test connection.
  7. If you want Takku to start with your Mac, turn on Open at login in Settings, General.

Profiles to start from

On your Mac
Start llama-server -hf ggml-org/gemma-4-E4B-it-GGUF:Q4_0 -c 32768, then use the base URL http://localhost:8080/v1 and the model ggml-org/gemma-4-E4B-it-GGUF:Q4_0, with no key. Ollama and LM Studio work too.
Regolo.ai, Italy
Base URL https://api.regolo.ai/v1, model gemma4-31b, with an API key.
Mistral, France
Base URL https://api.mistral.ai/v1, model mistral-medium-latest, with an API key.
OpenRouter, United States
Base URL https://openrouter.ai/api/v1, model openai/gpt-6-luna-pro or any other from its catalogue, with an API key. OpenRouter is outside the EU and passes your requests on to the model’s provider: Takku doesn’t stop you from using it, but know where your meetings go.

Set max context to the model’s real limit: for a local server, the -c it was started with. To keep only the transcript, choose Transcript as the profile.

Takku doesn’t check where a provider processes your data: read its terms, and your company’s policy, before using it for real meetings.

Reasoning and extra parameters

Reasoning sets how much the model thinks before it answers. Model default sends nothing and is the safe choice. With OpenRouter every level works on every model that reasons, because OpenRouter adapts it. Other providers get the same setting as OpenAI’s reasoning_effort, which not every model accepts. More reasoning also means a slower summary.

Extra parameters are for what a model needs beyond that: a JSON object, added to every request as you write it, in place of what Takku would send for the same key. The provider’s documentation says what to write. Two examples on TensorX:

DeepSeek V4
{"chat_template_kwargs": {"thinking": true}} makes it reason, which it doesn’t do by default.
Qwen 3.8
{"reasoning_effort": "xhigh"} gives it the most reasoning. It refuses Off and High from the menu.

If the provider refuses a value, the error says what the profile sets. Press Test connection after changing either one: it sends the same reasoning and extra parameters as a summary.

Updating

With Homebrew, run brew upgrade --cask takku. Otherwise quit Takku and replace it in Applications with the new version. Your settings, profiles, API keys and models are kept.

Coming from a 0.x version: from 1.0 Takku is signed with an Apple Developer ID, so macOS asks once more for the microphone, the system audio and the calendars, and for your password to let Takku read your saved API keys (choose Always Allow).
